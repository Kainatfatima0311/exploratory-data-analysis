# 📊 Exploratory Data Analysis (EDA)

A complete beginner-to-advanced Exploratory Data Analysis (EDA) repository built using Python.

This repository covers the complete EDA workflow with both theory and hands-on practical implementation.

## 📚 Topics Covered

- Introduction to EDA
- Dataset Understanding
- Missing Values
- Duplicate Data
- Data Cleaning
- Univariate Analysis
- Outlier Detection
- Bivariate Analysis
- Multivariate Analysis
- Data Visualization
- Complete EDA Project

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Kainatfatima0311/exploratory-data-analysis.git
```

Install the required libraries:

```bash
pip install -r requirements.txt
```
